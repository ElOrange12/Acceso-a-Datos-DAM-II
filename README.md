# 💾 Acceso a Datos (AD) - DAM

![DAM](https://img.shields.io/badge/Ciclo-DAM-blue?style=flat-square)
![Comunitat Valenciana](https://img.shields.io/badge/Currículo-Comunitat_Valenciana-orange?style=flat-square)

Repositorio de proyectos, prácticas y apuntes del módulo **Acceso a Datos (AD)**, correspondiente al 2º curso del Ciclo Formativo de Grado Superior en **Desarrollo de Aplicaciones Multiplataforma (DAM)**. 

Los contenidos y resultados de aprendizaje de este repositorio están estructurados de acuerdo con el currículo oficial establecido para la **Comunitat Valenciana** (Decreto 63/2012 del Consell, que desarrolla el Real Decreto 450/2010 a nivel autonómico).

---

## 📚 Resultados de Aprendizaje (RA)

De acuerdo con la normativa vigente, el módulo se centra en conseguir que el alumno alcance los siguientes objetivos:

| RA | Descripción | Estado |
|:---:|---|:---:|
| **RA1** | **Gestión de la información** en ficheros lógicos y físicos, utilizando clases estándar. | ⏳ Pendiente |
| **RA2** | **Desarrollo de aplicaciones** que acceden a bases de datos relacionales (conectores y JDBC). | ⏳ Pendiente |
| **RA3** | **Gestión de la persistencia** de datos mediante herramientas de mapeo objeto-relacional (ORM). | ⏳ Pendiente |
| **RA4** | **Desarrollo de aplicaciones** para el acceso a bases de datos objeto-relacionales y orientadas a objetos. | ⏳ Pendiente |
| **RA5** | **Desarrollo de aplicaciones** que gestionen bases de datos XML y bases de datos NoSQL. | ⏳ Pendiente |
| **RA6** | **Programación de componentes** de acceso a datos para su fácil integración en aplicaciones. | ⏳ Pendiente |

## 📂 Estructura del Repositorio

El repositorio está organizado para abarcar las unidades de trabajo del currículo de la Generalitat Valenciana:

*   📁 `UD01_Manejo_Ficheros/` - Ficheros de texto, binarios, acceso aleatorio, XML y JSON.
*   📁 `UD02_Conectores_BD/` - Patrón DAO, conexión a bases de datos relacionales mediante JDBC.
*   📁 `UD03_Herramientas_ORM/` - JPA e Hibernate (mapeo, consultas HQL/JPQL, transacciones).
*   📁 `UD04_BD_Objeto_Relacionales/` - Tratamiento de objetos persistentes en bases de datos.
*   📁 `UD05_BD_XML_y_NoSQL/` - Bases de datos orientadas a documentos (MongoDB), grafos y nativas XML (eXist-db).
*   📁 `UD06_Componentes_Acceso_Datos/` - Frameworks de acceso a datos y repositorios (ej. Spring Data).

---

## 🛠️ Tecnologías y Herramientas

A lo largo de las distintas unidades se utilizarán diversas tecnologías clave para la gestión de la persistencia:

*   **Lenguajes:** Java, SQL, XQuery / XPath.
*   **Bases de Datos:** MySQL / PostgreSQL (Relacionales), MongoDB (NoSQL), eXist-db (XML).
*   **Frameworks y Librerías:** JDBC, Hibernate, Java Persistence API (JPA), Spring Boot.
*   **Formatos de Intercambio:** XML, JSON, CSV.
*   **Entornos y Herramientas (IDEs):** IntelliJ IDEA, Eclipse, DBeaver, Maven/Gradle.
